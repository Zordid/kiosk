# js-dos

The files in this directory are an unmodified excerpt of
[js-dos](https://js-dos.com) 8.5.3 by Alexander Guryanov (caiiiycuk),
as published on npm (`js-dos@8.5.3`): the player (`js-dos.js`,
`js-dos.css`) and, under `emulators/`, the DOSBox backend and its helpers
(the DOSBox-X backend of the package is left out; Kiosk does not need it).
js-dos runs DOSBox, compiled to WebAssembly, in the browser.
